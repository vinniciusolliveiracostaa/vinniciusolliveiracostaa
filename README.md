## Profile

Software engineer focused on backend systems, DevOps, Linux-based infrastructure, and solutions architecture. I design and build systems from domain modeling to deployment, with attention to service boundaries, operational clarity, observability, and long-term maintainability.

My principal stack spans **TypeScript, Go, and Rust**. I use TypeScript for product and platform development, Go for backend services, infrastructure tooling, networking, and operational systems, and Rust for reliable systems software, lower-level components, performance-sensitive services, and projects where correctness and control matter from the beginning.

On the frontend side, my current direction is closer to **SolidJS, TanStack, Rsbuild, TailwindCSS, and modern toolchain composition**. I have experience with React, Next.js, NestJS, Prisma, and TypeORM, but I currently prefer smaller, more explicit stacks when the project benefits from control, clear boundaries, and operational simplicity.

I identify professionally as **CTO & Founder @dacostatechnologies**, building from a systems-first perspective: understand the domain, design the boundaries, automate the operation, and keep the platform understandable enough to debug under pressure.

## Operating principles

- Understand the system before abstracting it.
- Keep architecture explicit, testable, and operable.
- Prefer simple boundaries over accidental complexity.
- Use Go, Rust, and TypeScript as primary engineering tools, not only as niche optimizations.
- Build infrastructure that can be reproduced, debugged, and explained.
- Treat code generation and tooling as accelerators, not substitutes for engineering judgment.
